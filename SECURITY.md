# Security Policy

This repository contains data element mappings, vocabulary files, and analysis scripts. It does not contain participant-level data or protected health information, and it does not distribute deployable software.

## Supported Versions

Only the latest version on the `main` branch is maintained. Tagged releases (e.g., `v1.0-tvst`) are archived snapshots and are not updated.

## Reporting a Concern

Please **do not** report security or privacy concerns in public issues. This includes:

- Participant-level data, protected health information, or restricted-access AI-READI data accidentally committed to this repository
- Credentials, tokens, or other secrets found in the repository or its history

Email <security@aireadi.org> with the file path, commit, and a short description. We will acknowledge receipt and remove affected content as quickly as possible.

For incorrect mappings or other non-sensitive problems, please [open an issue](https://github.com/AI-READI/DataElementMaps/issues).
